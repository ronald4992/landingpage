# Mundo de criaturas mágicas

Landing page fan no oficial sobre las criaturas mágicas de Harry Potter. Está creada con HTML y CSS, con cliente y servidor en TypeScript sobre Node.js.

## Ejecutar en local

```sh
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Compilar y ejecutar

```sh
npm run build
npm start
```

El servidor solo entrega la página, los estilos y el cliente compilado. El puerto se puede cambiar con la variable `PORT`.
